# results

One file per measured configuration: `<yyyy-mm-dd>-<label>.result.json`, written by `python3 -m strata_bench run ...` and checked with `python3 -m strata_bench validate`.
Add yours in a pull request; see [docs/SUBMIT.md](../docs/SUBMIT.md). After a merge, `docs/data.json` is rebuilt and the dashboard updates.
