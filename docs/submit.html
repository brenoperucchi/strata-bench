The result becomes public. It is added to the dashboard through a pull request that is checked again by CI and merged by a maintainer, so it can take a little while to appear.

Other ways to submit

One-click upload is not enabled on this page yet. Your file is valid, so you can send it either way:

  • Open a pull request that adds it under results/ (guide).
  • Or open an issue and attach the file.

The check runs entirely in this page; the file leaves your browser only when you press the send button.
